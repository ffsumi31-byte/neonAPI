A CLEAR START

Before you connect.

How will installation work on my computer?

Windows setup will use PowerShell. Linux setup will use a terminal shell. On macOS, shell setup runs in the Terminal app (Applications → Utilities → Terminal). Platform installers are not published yet, so there is no install command to run today. Once deployed, this website itself opens in a browser on all three systems without installing Node.js. Do not paste commands that include provider keys or run unverified download scripts.

Which API key do I use here?

A customer key starting with sk-gw-, issued privately by this service’s administrator. Provider keys stay on the server. This page cannot create or purchase a customer key.

Do my tokens expire?

No. This portal’s allowance is lifetime: additional grants accumulate, and there is no monthly reset. Actual deductions are not enabled yet.

What’s ready, and what comes next?

The portal has key login and a database-backed account API. It needs a deployed Netlify project and PostgreSQL database. Provider inference, enforced usage settlement, payments, automatic helper workflows, and installers are not enabled.

What do the model presets mean?

They describe planned service workflows and credit weights, not guaranteed improvements in quality or actual Claude models. Preset selection is only a UI preview. It does not change the existing local gateway.
